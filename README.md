# Philadelphia Creative Alliance

The website for the Philadelphia Creative Alliance — a network connecting visual and physical
artists across Greater Philadelphia: painters, muralists, sculptors, ceramicists, printmakers,
and performers. Clients discover local makers by discipline; makers find each other.

**Live at** https://philadelphiacreativealliance.com

## This repo

A single, self-contained static page — `index.html` with inline CSS and vanilla JS, no build step.
Hosted on GitHub Pages (`CNAME` + `.nojekyll`).

Local preview:

```bash
python3 -m http.server 8080   # then open http://localhost:8080
```
